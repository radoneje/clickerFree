# Требования к сервису

Статус: проектирование. Требования ниже задают первую версию; численные ограничения приведены в [политике защиты](security.md).

## Назначение

Любой желающий может бесплатно зарегистрироваться, привязать свой компьютер и переключать презентацию из браузера. Установка приложения на телефон не нужна. Компьютер и телефон должны иметь доступ к интернету. Переключение работает в активном окне презентации; сервис не получает её содержимое.

## Роли

- **Владелец аккаунта:** управляет своими компьютерами, пультами, таймерами и приглашениями.
- **Спикер:** использует временную ссылку с доступом к одному компьютеру без регистрации.
- **Администратор сервиса:** видит общую статистику, релизы, ошибки и ограничения пользователей. Эта роль не даёт права переключать чужие презентации.

## Публичный сайт и кабинет

На главной: описание возможностей, три шага подключения, поддерживаемые ОС, скачивание, FAQ и вход. В кабинете: список компьютеров, название, статус, версия воркера, время последней связи, управление, таймер, приглашения и отзыв доступа. Настройки аккаунта позволяют привязать второй способ входа и завершить другие сессии.

Вход через VK ID или Яндекс ID. Один внутренний аккаунт может иметь обе привязки. Объединение выполняется только после подтверждённого входа; совпадения email недостаточно.

## Привязка компьютера

1. Пользователь скачивает и запускает воркер.
2. Воркер показывает одноразовый код и открывает страницу привязки.
3. Пользователь входит в кабинет, проверяет название компьютера и подтверждает привязку.
4. Сервер выдаёт воркеру отдельные учётные данные; компьютер появляется в кабинете.

Код не является постоянным паролем. UUID идентифицирует установку, но сам по себе не даёт доступа. Отвязка отзывает ключ и разрывает активное соединение. Повторный запуск на том же компьютере не создаёт новое устройство.

## Пульт и приглашение спикера

Пульт содержит крупные кнопки «Назад» и «Вперёд», статус связи и таймер. Поддерживает стрелки клавиатуры, портретную и альбомную ориентацию. При потере связи управление блокируется, старые команды не накапливаются.

При создании ссылки владелец выбирает:

- компьютер;
- язык пульта: русский или английский;
- срок действия — по умолчанию 2 часа, максимум 24 часа;
- дополнительный пароль при необходимости.

Кабинет выдаёт ссылку и QR-код. Приглашение позволяет только переключать выбранный компьютер и видеть его таймер. Настройки аккаунта, другие компьютеры и статистика недоступны. Владелец может отозвать приглашение и завершить доступ уже подключённых пультов.

Несколько пультов допускаются в пределах лимита. Для одного компьютера по умолчанию действует один управляющий сеанс; передачу управления подтверждает владелец. Остальные пульты видят состояние без отправки команд.

## Локализация

Поддерживаются `ru` и `en`. Язык сайта и кабинета хранится в профиле, до входа — в cookie. При первом посещении используется поддерживаемый язык браузера, иначе `ru`.

Язык пульта хранится отдельно. Для нового пульта приоритет: явный выбор пользователя → язык приглашения → язык браузера → `ru`. При открытии другой ссылки её язык используется, пока пользователь не выберет свой. Настройка пульта не меняет язык кабинета, и наоборот. В URL приглашения допустим `lang=ru` или `lang=en`; это только настройка отображения, не полномочие.

**Все пользовательские сообщения сразу реализуются на русском и английском:** кнопки, ошибки, уведомления, формы, статусы, доступность, страницы входа и обновления, сообщения воркера и инструкции по установке. Двуязычность означает две локализации, а не одновременное отображение двух текстов. На страницах провайдера входа язык зависит от возможностей провайдера.

Тексты хранятся по ключам в словарях. Сервер передаёт стабильный код ошибки и параметры; клиент выбирает перевод. Проверка сборки выявляет отсутствующие ключи и несовпадающие параметры переводов. Даты, числа и длительности форматируются с учётом языка. Воркер имеет отдельную настройку языка; по умолчанию использует язык ОС.

## Версии воркера

При каждом запуске и подключении проверяются версия приложения, ОС, архитектура и версия протокола. Сервер сообщает последний релиз и минимально допустимую версию. Совместимое обновление предлагается ненавязчиво; неподдерживаемая версия не допускается к управлению. При недоступности проверки показывается понятный статус и выполняется повторная попытка. Проверка на старте не заменяет серверную проверку совместимости.

В первой версии обновление ручное. Обновления не устанавливаются во время выступления. Поддерживаются Windows x64 и macOS arm64/x64; конкретные минимальные версии ОС фиксируются после проверки сборок.

## Статистика

Администратору доступны запросы скачивания по ОС и версии, первые запуски, привязки, активные пользователи за день/неделю/месяц, сеансы управления, длительность, количество команд и ошибок, распределение версий. Есть фильтр периода и выгрузка агрегатов CSV.

Запрос загрузки, фактическая передача файла и первый запуск считаются разными событиями. Первый запуск — первое обращение установки к сервису, а не доказательство уникального физического компьютера. Сеанс использования начинается с первой принятой команды, завершается явно либо после 15 минут без команд; соединение без действий не считается использованием. Разрыв связи ограничивает измеряемую длительность. Время обработки измеряется на сервере; это не время фактического переключения слайда.

## Дизайн и приёмка

Минималистичный светлый интерфейс, нейтральный фон, один акцентный цвет, ясная типографика. На компьютере — список устройств и панель управления; на телефоне — карточки и отдельный полноэкранный пульт. Без горизонтальной прокрутки при ширине 320 px; управление доступно с клавиатуры, кнопки имеют подписи для экранного диктора, статус не передаётся одним цветом.

Первая версия принимается после проверки обоих входов, изоляции двух пользователей, привязки и отзыва устройства, приглашения на обоих языках, независимости языков, таймера, переподключения без повторных команд, проверки версий и корректности статистики. Обязательны проверки ограничений из документа по защите.
